# vologda-brus-site

Сайт «Вологда Брус» на Nuxt 4 — перенос оформления и содержания с текущего
сайта на Тильде (`вологдабрус.рф`) в собственный проект.

Перенесены вёрстка, тексты и фотографии. Код платформы Тильды не копировался:
компоненты, стили и скрипты написаны заново, поэтому попутно закрыты
технические проблемы из аудита (`../Работа по сайту/Аудит сайта вологдабрус.рф.md`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run generate   # статика в .output/public + sitemap.xml
npx serve .output/public   # посмотреть собранное
```

Нужен Node 20+ (проверено на 26).

## Структура

```
app/
  assets/
    scss/           дизайн-система: токены, миксины, сброс, шрифты
    fonts/          Open Sans локально (4 подмножества, переменное начертание)
  components/
    ui/             базовые: BaseButton, SmartImage, SectionHeader,
                    GalleryGrid, BeforeAfter, FormField, RadioGroup, IconChat
                    (без префикса папки — см. nuxt.config)
    layout/         SiteHeader, SiteFooter, MessengerModal, CookieBanner
    sections/       блоки главной, по одному на секцию
  composables/
    useImage        srcset и пропорции из манифеста картинок
    useSeo          title, description, canonical, Open Graph
    useLeadForm     отправка заявки
    useMessengerModal
  data/
    site.ts         контакты, реквизиты, навигация, мессенджеры
    content.ts      тексты секций главной
    posts.ts        статьи блога
    policy.ts       текст политики конфиденциальности
    images.json     манифест: доступные ширины и реальные размеры
  pages/            index, blog, blog/[slug], contacts, dealers, privacy-policy
  error.vue         404
public/images/      пережатые картинки: WebP 640/1024/1600 + JPEG
scripts/sitemap.mjs карта сайта из реально собранных маршрутов
_source/            разбор исходника Тильды (в репозиторий не идёт)
```

Содержание отделено от вёрстки: правка телефона, адреса или текста секции —
это правка `app/data/*`, а не обход компонентов.

## Что изменилось против версии на Тильде

| | Тильда | Здесь |
|---|---|---|
| HTML главной | 805 КБ (115 КБ сжатый) | 65 КБ (12,5 КБ сжатый) |
| CSS | 364 КБ встроено в каждую страницу | 49 КБ отдельными файлами, скачиваются один раз |
| JS | ~2 МБ, 24 файла | 352 КБ (карта — ещё 1 МБ, но только когда доедешь до неё) |
| Вес при загрузке | — | 0,99 МБ |
| Картинки при полной прокрутке | 22,5 МБ оригиналами | 5,0 МБ целиком со скриптами и шрифтами |
| Формат картинок | только JPEG/PNG | WebP + JPEG, 3 ширины, `srcset` |
| `<title>` главной | «Главная» | с запросом, регионом и брендом |
| `description` | нет ни на одной странице | на всех, включая пять статей |
| `<h1>` | нет ни одного на сайте | по одному на страницу |
| Кнопки-призывы | 15 штук через `javascript:` | настоящие ссылки |
| Шрифты | 3 блокирующих запроса к Google, Jura и Manrope не использовались | локально, только Open Sans |
| Микроразметка | 63 пустых `ImageObject` | `LocalBusiness` + `BlogPosting` |
| Список статей | рисуется скриптом, ссылок нет | обычные страницы в карте сайта |
| Защита форм | нет | honeypot + проверка полей |
| Страница дилеров | нет (а пункт меню есть) | `/dealers` |
| Страница контактов | нет | `/contacts` с картой и графиком |
| Реквизиты и карта | нет нигде | полоса над подвалом на всех страницах |

Сетка повторяет Тильду: до 1200 px колонка 940 (три карточки по 300 с шагом
20), шире — колонка 1160 (три по 360 с шагом 40). Миксины `t-container`
и `t-cols-3` в `app/assets/scss/_mixins.scss`.

Появление блоков при прокрутке перенесено вместе с параметрами оригинала
(`app/plugins/reveal.ts`, директива `v-reveal`): выезд слева и справа на
100 px за 0,5 с, проявление за 1 с, приближение с 0,9 — кривая
`cubic-bezier(.19,1,.22,1)`, цепочки с шагом 0,16 с. Отличие одно: прячущий
класс навешивает браузер, поэтому при выключенном JS страница показывает всё
сразу, а не остаётся пустой. При `prefers-reduced-motion` анимации выключены.

Ленты «Производство в Вологде» и снимков производства листаются мышью
(перетаскиванием), кнопками и сами по себе раз в 5 секунд — пауза при
наведении, фокусе и при `prefers-reduced-motion` (`app/composables/useCarousel.ts`).

Полоса с реквизитами и картой производства (`app/components/layout/ContactsMap.vue`)
стоит над подвалом на всех страницах. Карта — MapLibre GL на тайлах OpenFreeMap,
тёмный стиль; библиотека грузится только когда блок доезжает до экрана, а при
ошибке на её месте остаётся тёмная подложка и адрес текстом. Отдельный файл
воркера MapLibre кладёт в `public/vendor/` скрипт `scripts/copy-maplibre.mjs`
(он же вызывается из `npm run dev` и `npm run generate`).

Страницы блога, статьи, политика и 404 сверены со страницами Тильды по
координатам, кеглям и цветам: экран-обложка блога 700 px, лента в три колонки
по 300 px с шагом 20, колонка статьи 620 px, текст 18/25,2, плашка 404 с
нарисованным домом перенесена вместе с графикой.

Исправлены опечатки: «оффертой» → «офертой», «Выберете» → «Выберите»,
«клеёного» → «клееного», лишний пробел в «200 р/м ²», кавычки в
«Двойной брус», убрана заглушка «Tilda Publishing», год в подвале считается,
а не вписан.

## Развёртывание

`npm run generate` даёт статику в `.output/public` — её раздаёт любой
веб-сервер. На сервере остаётся настроить то, что из статики не задать:

- переадресацию `http://` → `https://` и `www` → основной домен;
- `Strict-Transport-Security`, `X-Content-Type-Options`, `Referrer-Policy`;
- кэширование: `/_nuxt/*` и `/images/*` — надолго (имена с хешем),
  HTML — коротко с проверкой;
- сжатие (gzip или brotli) для HTML, CSS, JS и SVG.
